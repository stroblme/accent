# Bundled font

`STIXTwoMath-Regular.otf` is STIX Two Math 2.13 (b171), from https://github.com/stipub/stixfonts
tag `v2.13b171`, path `fonts/static_otf/STIXTwoMath-Regular.otf`, as formulary 0.3.0 vendors it.
It is licensed under the SIL Open Font License 1.1 (`OFL.txt` in this directory).

It is the font the tests lay out with, and the one the app draws formulas with where the system
has no OpenType MATH font.
