# Keyboard shortcuts

You can do almost everything from the keyboard.
Press `Ctrl+P` to search commands by name, including commands without a shortcut.
For the full list, choose **Keyboard Shortcuts** from the main menu or press `Ctrl+?`.

| Action | Shortcut |
| --- | --- |
| New File | `Ctrl+N` |
| Open File… | `Ctrl+O` |
| Go to File… | `Ctrl+E` |
| Run a Command… | `Ctrl+P` |
| Search Pane | `Ctrl+Shift+F` |
| Find in the open document | `Ctrl+F` |
| Replace in the open document | `Ctrl+H` |
| Save | `Ctrl+S` |
| Toggle Preview | `Ctrl+M` |
| Split Right | `Ctrl+\` |
| Next recently used tab | `Ctrl+Tab` |
| Close Tab | `Ctrl+W` |
| Toggle Sidebar | `F9` |
| Presentation Mode | `F5` |

Shortcuts for a [PDF](pdf.md), [diagram](diagrams.md), [notebook](notebooks.md), [terminal](terminals.md) or [debug session](debugging.md) depend on what is in front.
The in-app shortcut list shows those keys too.

## Change a shortcut

Open **Run a Command…** and click the keys beside a command to assign a new shortcut.
Press `Backspace` there to leave it unbound, or choose **Restore Default** to bring its original keys back.
Accent warns you if another command already uses the keys.
An unbound command stays in the palette, so you can always find it again.
